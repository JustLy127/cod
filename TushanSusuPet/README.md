# 涂山苏苏宠物迁移素材

作者：legeling。来源：https://github.com/legeling/awesome-codex-pet/tree/022aea52f75841d31f57b7596479ebb425480a50/pets/tushan-susu--legeling

- `compatible/spritesheet.webp`：已在当前账号使用并验证的 v2 兼容精灵图；重新导入账号时使用此文件。
- `package/tushan-susu--legeling/`：作者原始素材、pet.json 和 submission.json。
- `SOURCE.json`：公共来源、版本和兼容素材哈希，不含旧账号 ID。
- `ASSETS-LICENSE.md` 与 `LICENSE`：素材许可与仓库代码许可。

同一账号先去新电脑的“设置 → Mini 与宠物”选择已有苏苏并打开 Mini。不同账号使用兼容精灵图重新导入；仅复制到 `.codex/pets` 不能替代账号导入。精灵图不需要重新生成。

兼容版只清空闲置行未使用的重复格，全部 73 个有效格像素保持一致。
