# 涂山苏苏 · Codex 启动动画

点击桌面或开始菜单的 **Codex - 涂山苏苏**：Codex 已运行时直接唤回现有主窗口；完整退出后再打开时播放苏苏开场，并让 Codex 保持最大化。动画本体约 7 秒，会等主界面和本次主题加载成功后再交接。开场中按 **Esc** 或右上角“跳过”可立即隐藏动画，启动流程会在后台继续完成。

开场使用内置 image_gen 生成的苏苏主题插画，配合程序实现的缓慢镜头推进、飘落花瓣、文字淡入和真实窗口过渡；默认静音。插画与最终生成提示词位于 `media/`。它是一段插画动效。

## 日常使用

- 请从新建的 **Codex - 涂山苏苏** 图标启动，才能播放动画。
- Codex 已显示、最小化或关闭到托盘时，入口调用 Codex 自身的恢复流程，唤回已有主窗口，不重跑开场或主题加载。启动器会记录实际主窗口的身份；隐藏窗口必须同时匹配窗口标记、所属进程及其启动时间，避免把后台辅助窗口误当主界面。恢复请求沿用已核验的本机调试端口，不直接强制显示官方窗口。
- 刚完整退出后若旧进程仍在清理，本次双击会先显示开场，等旧进程自然退出后继续启动，无需再双击一次。启动器不会强行终止 Codex。
- 完整退出后的启动仍会等待窗口稳定、本次主题成功和 400 毫秒绘制时间。较慢时会继续显示开场，最长约 120 秒；准备好即可提前交接，失败、超时或手动跳过仍会释放。
- 完整退出后的新启动默认最大化，开场覆盖显示器工作区，不再跟着刚出现的小窗口缩小。这里的最大化保留系统标题栏和任务栏。
- 已运行的 Codex 按窗口当前的位置、大小和最大化状态恢复。手动调整为小窗后，再从托盘或最小化状态打开，保持该小窗大小；启动器不缓存旧尺寸。
- 非 16:9 开场用柔和背景填充，保留完整文字和跳过按钮。
- 启动器目录需要完整保留，尤其是 `FoxSpiritCodexBoot.exe`、`launcher.json` 和 `media/`。
- 直接双击程序也能播放；运行 `FoxSpiritCodexBoot.exe --preview` 只预览开场。
- 已接入相邻 `TushanSusuTheme` 目录的“涂山苏苏 · 花映青山”运行时主题。首次启用请从 Codex 菜单或系统托盘完整退出，再从苏苏图标打开；主题包和恢复入口见相邻目录的使用说明。

## 安装、迁移与移除

`Install-Shortcuts.cmd` 只管理桌面和当前用户开始菜单中名为 **Codex - 涂山苏苏** 的两个入口；同名旧文件会先备份。恢复脚本会保留你之后自行改动的快捷方式。

停止使用或移动本目录前，双击 **Restore-Shortcuts.cmd** 移除本启动器创建的入口、恢复可能存在的同名原入口。迁移后在新位置双击 **Install-Shortcuts.cmd** 重新创建入口。

## 验证范围

版本 1.0.4.0 已通过 Windows x64 编译、46 项主窗口身份/复用/尺寸策略回归、26 项官方恢复入口与端口核验回归、19 项启动就绪/失败/超时回归，以及 7 组显示器布局和 2,828 组过渡矩形几何检查。实际重复打开约 1.13 秒，窗口身份、大小、正常窗口位置和最大化状态保留，未新增客户端进程、未重跑主题或开场，桌面快捷方式指向新版，见 qa/size-fix-warm-verification.json。

1.0.3.0 直接显示隐藏的原生窗口，可能留下“外壳可见、内部页面仍隐藏”的状态。实测故障时主页面 visibility=hidden，1.5 秒没有绘制帧；1.0.4.0 改为官方单实例入口执行完整恢复，随后主页面 visibility=visible、恢复绘制，仍是原来的进程、窗口和页面。用户已确认页面操作、最大化、关闭及托盘重开正常，且保留调整后的窗口大小，见 qa/tray-lifecycle-verification.json。快捷方式安装、恢复和中断恢复逻辑未修改。

旧版本只凭窗口响应就提前结束开场，因此会露出官方白底加载画面。1.0.1.0 改为等待本次主题启动进程确实成功，忽略历史成功记录，再进行实时窗口过渡。旧版实际交接检查见 qa/handoff-warm-verification.json；用户已确认完整退出后不再露出白底 Logo，见 qa/cold-start-user-acceptance.json。1.0.4.0 保留 1.0.3.0 的退出清理等待、同一次启动继续和冷启动最大化流程。

## 配置与来源

`launcher.json` 可调整动画总时长和等待节点；MaxWaitSeconds 默认 120 秒，包含等待旧进程退出的时间。`MaximizeColdStart: true` 使完整退出后的新启动保持最大化，不影响已有窗口恢复。将其设为 false 后，`WindowSizing: "MatchCodex"` 让开场跟随 Codex 的大小；设为 `"Fixed"` 则使用 `PlayerWidth` 和 `PlayerHeight` 的 16:9 固定窗口尺寸。当前配置对应本机注册的 `OpenAI.Codex_2p2nqsd0c76g0!App`。

窗口查找与 DWM 实时缩略图衔接方法参考 [Dragon Codex Boot](https://github.com/yushua0808-cpu/dragon-codex-boot)，代码保留 MIT 许可证及来源声明。苏苏主题插画由内置 image_gen 生成，完整最终提示词见 [media/generation-prompt.txt](media/generation-prompt.txt)。角色与作品名称属于各自权利人，本启动器为个人主题定制，与 OpenAI 或《狐妖小红娘》官方无隶属关系。

源码和构建脚本在 `source/`；启动日志在 `logs/launcher.log`；主窗口身份在 `state/primary-window.json`，仅保存窗口句柄、进程编号、进程启动时间和随机窗口标记，不保存窗口尺寸。启动器在本地运行，日志不记录聊天正文、窗口标题或截图。
