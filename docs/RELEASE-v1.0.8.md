# v1.0.8 修复悬停提示看不清

在 Codex `26.1106.6628.0` 上悬停于左侧圆形入口时，苏苏主题让提示文字和底色变成了同一种深色。v1.0.8 为悬停提示使用暖白底和深色文字，也包含 v1.0.7 的主窗口白底修复。

## 已安装的电脑

1. 下载本次发布附带的 **cod-windows-x64-v1.0.8.zip**，完整解压到新的临时文件夹。
2. 保存任务，从 Codex 菜单或托盘完整退出客户端。
3. 双击新包中的 **Update-Theme.cmd**，等待更新成功。
4. 使用原来的 **Codex - 涂山苏苏** 快捷方式打开。

更新程序会找到原安装目录，备份并替换两个主题文件。每台已安装的电脑各运行一次。若找不到原目录，可按说明手动指定。[安装与更新说明](https://github.com/JustLy127/cod#已安装如何更新主题)

## 首次安装

先安装并登录官方 Codex。将完整包解压到长期保留的文件夹，双击 **Install.cmd**。
