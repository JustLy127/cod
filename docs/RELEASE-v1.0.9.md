# v1.0.9 修复 Codex 更新后主题加载超时

Codex `26.1117.3838.0` 更换了主内容区的界面标记。旧版主题识别不到主内容区，启动器等待约 35 秒后进入默认界面。v1.0.9 支持新版标记，也能识别旧版界面，包含此前的白底和悬停提示修复。个人资料页的背景插图也可正常显示。

已在 Codex `26.1117.3838.0` 上验证主窗口背景、配色和输入框。

## 已安装的电脑

1. 下载本次发布附带的 **cod-windows-x64-v1.0.9.zip**，完整解压到新的临时文件夹。
2. 保存任务，从 Codex 菜单或托盘完整退出客户端。
3. 双击新包中的 **Update-Theme.cmd**，等待更新成功。
4. 使用原来的 **Codex - 涂山苏苏** 快捷方式打开。确认主题生效后，可以删除新版临时解压目录，保留原安装目录。

更新程序会找到原安装目录，备份并替换两个主题文件。每台已安装的电脑各运行一次。若找不到原目录，可按说明手动指定。[安装与更新说明](https://github.com/JustLy127/cod#已安装如何更新主题)

## 首次安装

先安装并登录官方 Codex。将完整包解压到长期保留的文件夹，双击 **Install.cmd**。
