# v1.0.7：修复 Codex 更新后的白色背景

Codex 26.1029.7803.0 改变了主内容区和输入框的样式名称，旧版主题因此无法识别新版主窗口。本版同时兼容旧、新两种命名，恢复苏苏背景及暖白粉色配色，继续使用轻量 CSS，避免增加滚动监听和页面扫描。

## 已经安装的电脑

1. 下载本 Release 附带的 **cod-windows-x64-v1.0.7.zip**，完整解压到新的临时文件夹。
2. 保存任务，从 Codex 菜单或托盘完整退出客户端。
3. 双击新包中的 **Update-Theme.cmd**，等待更新成功。
4. 使用原来的 **Codex - 涂山苏苏** 快捷方式打开。

补丁自动寻找原来的快捷方式，只替换两个主题兼容文件，并保留动画、启动器配置及宠物素材。无需重新登录或导入宠物。更新成功后，临时新包可以删除；原安装目录需要保留。若无法自动定位，可按 README 指定原安装目录。

## 新电脑首次安装

将完整包解压到长期保留的文件夹，双击 **Install.cmd**。先安装并登录官方 Codex；新账号的宠物导入见 `docs/PET-IMPORT.md`。

已在 Windows x64 官方商店版 Codex **26.1029.7803.0** 验证主题背景、文字对比度和页面绘制。旧版/新版界面识别及辅助窗口排除测试通过。启动器仍使用已验证的 1.0.4.0，保持冷启动最大化、托盘唤回保留大小的逻辑。

每台已安装电脑需分别更新；项目目前没有自动更新功能。
