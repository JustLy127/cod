# 苏苏主题轻量兼容加载器

当前客户端：OpenAI.Codex 26.1013.4894.0。主题素材仍为 tushan-susu-blossom 1.0.0，运行时外观实现已升级为第 3 版。

## 覆盖范围

在原生应用主框架内，聊天、设置和其他页面共享暖白、莓粉与深色文字配色，同文档内的菜单、列表和弹窗使用相同颜色。主面板和侧栏保留苏苏插画，输入区保持清晰的暖白底板。

Mini、苏苏宠物、登录和独立辅助窗口不会被主界面主题覆盖。系统原生菜单及第三方网页不属于此 CSS 的覆盖范围。

## 性能修复

旧版本叠加了上游及两套兼容监听，会在滚动、流式回复和界面变化时反复扫描 DOM 与读取布局。旧验证还要求可见聊天输入框，设置页可能因此被错误撤销主题。

当前 modern-appearance.js 使用纯 CSS 和原生颜色变量，没有主题 MutationObserver、计时器、滚动或窗口尺寸监听。页面切换和流式回复无需重新扫描。图片只解码一次并保存在 Blob URL；取消固定背景和主题面板的玻璃模糊。

loader.mjs 不再运行旧版适配器的 apply 或动态打标逻辑。旧版适配器只用于清理历史样式与监听，文件哈希仍会核验。新版本会清除旧 composer、appearance 和上游监听，再应用一份 CSS。

后台每 10 秒检查页面的轻量版本标记，已验证的进程与本机端口缓存 120 秒；连接失效时重新发现。图片和完整外观验证只在首次加载或版本升级时执行。关闭的页面连接会及时清理。状态文件合并写入，不在每轮重复执行完整验证。

## 使用与恢复

继续使用桌面“Codex - 涂山苏苏”启动。此次修复已直接应用于正在运行的客户端，无需重启。

- Start-ManagedCodex.ps1 与 Discover-Codex.ps1 继续核验官方 Appx 身份、进程与随机回环调试端口归属。
- loader.mjs --watch 负责新窗口与重载后的自动加载；单实例锁避免重复后台运行。
- Restore-Theme.cmd 调用 Manage-Theme.ps1，设置停用标记并移除主题、监听和 Blob URL。
- Enable-Theme.cmd 接回原有启动入口。
- runtime-data/compat-status.json 为当前状态，mode 应为 native-css-lightweight。
- runtime-data/compat.log 记录应用、恢复与错误事件。
- qa/lightweight-runtime-verification.json 为真实运行检查结果。
