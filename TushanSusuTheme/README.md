# 涂山苏苏 · 花映青山

本迁移包附带苏苏主题素材 1.0.0 与第 3 版轻量外观实现。聊天、设置等主框架页面共享暖白、莓粉与深色文字配色；主面板和侧栏保留苏苏插画。Mini 保持独立外观。

请先运行上一级 **Setup.cmd**，再完整退出 Codex 并从桌面“Codex - 涂山苏苏”启动。不要在运行 Setup 前单独启动脚本。Setup 会生成新电脑的 Node 路径，并导入所需主题存储；无需复制旧电脑的 runtime-data。

兼容加载器仅连接经过核验的官方 Codex 所属本机回环端口，不修改 Codex 安装包。运行时界面使用纯 CSS；后台轻量检查新页面，保持主题。实现与许可见 compat 目录。

恢复默认使用 **Restore-Theme.cmd**；重新启用可运行上一级 **Setup.cmd**。默认恢复后还需正常退出一次 Codex，结束本次主题会话。

runtime 目录保留 OpenChatGPTSkin 0.4.2 的命令行运行工具及许可，未携带其无关主题和网页编辑器。本主题接入使用相邻 compat 目录的独立加载器。

当前适配验证过的客户端版本：OpenAI.Codex 26.1013.4894.0。不同版本需在新电脑实际核对。
